# Fitness Booking Service 

Сайт для бронирования занятий фитнесом с системой авторизации и хранением данных в localStorage.

## Назначение проекта

Автоматизация записи клиентов на занятия (йога, пилатес, растяжка, здоровая спина). 
Пользователи просматривают расписание, записываются и отменяют записи.

## Возможности пользователя

- Просмотр расписания занятий с ценой и временем
- Регистрация и вход 
- Запись на занятие через модальное окно
- Личный кабинет
- Отмена записи в один клик

## Работа с данными

Хранение реализовано через **localStorage** браузера:

| Ключ | Данные |
|------|--------|
| `app_users` | Список пользователей (логин, email, пароль, ID) |
| `app_current_user` | Текущая сессия |
| `app_bookings` | Бронирования (дата, время, цена, ID пользователя) |

**Валидация:**
- Email должен быть корректным
- Пароль: минимум 8 символов, буквы и цифры
- Логин и email уникальны
